Method

How to read and reproduce these numbers

  • Retrieval runs on BEIR (SciFact, NFCorpus, FiQA) and on LongMemEval_S session retrieval over 470 questions.
  • Each agent question ran once. Judge noise alone flipped about 4 of 56 answers between runs, so a gap smaller than 5 is not significant.
  • LongMemEval's histories come from public chat datasets. Real agent memory is shorter and more curated.
# each needs Docker and Go; agents also need the claude CLI
python3 bench/beir.py
python3 bench/rankers.py
python3 bench/run.py
python3 bench/longmemeval.py
python3 bench/run.py --trials 1 \
  --tasks-file bench/data/longmemeval/agent/holdout.json
